# OPT-2A

Optical tube leveling amplifier (AU / VST3, macOS universal) by Herigama Audio.
Model fitted to measurements of a tube opto leveler: static curves, two-stage optical release,
tube output stage, HF lift and the harmonics it adds. Built-in illustrated manual (`?` on the panel).

Build: `cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build --target OPT2A_AU OPT2A_VST3 dsp_test`
