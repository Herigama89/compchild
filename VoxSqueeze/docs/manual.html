Introduction

VoxSqueeze is a vocal leveler built around one idea: pull one fader down and the vocal comes forward. Compression and makeup gain are tied together on the COMP fader, so you never have to balance threshold against output: the loudest peaks stay where they were while the quieter words, breaths and tails are brought up. A gate on the left keeps the noise between phrases down, and a 0 dBFS look-ahead limiter at the end catches anything that would overshoot.

It works on lead and backing vocals, voice-over and podcasts, and on any single instrument that needs to sit at a steady level — bass, acoustic guitar, a horn line.

Quick start

  1. Insert VoxSqueeze on your vocal track. It loads with GATE off, COMP at 0 (no compression) and GAIN at 0 dB.
  2. Play the track and pull COMP down. Watch the orange GR meter: 3–6 dB for a natural level, 8–12 dB for an upfront pop vocal.
  3. The vocal also gets louder as you go — that is the automatic makeup gain. If it is now too loud in the mix, bring GAIN down (or the mixer fader).
  4. If background noise or headphone bleed comes up between phrases, raise GATE until the white light under it goes out in the gaps, then back it off a little.
Because COMP adds makeup gain, a quiet signal can come out much louder than it went in (up to about +52 dB at the very bottom of the fader). The limiter keeps peaks under 0 dBFS, but always check the level with GAIN before you print.

Signal path

Input→Gate→Comp + automatic makeup→Gain→Limiter (−0.1 dBFS)→Output

The gate and compressor listen to the louder of the two channels and apply the same gain to both, so the stereo image never shifts.

Controls

1Gate

A downward expander that turns quiet sounds down when the vocal stops: room noise, headphone bleed, chair creaks. The fader sets the level in dBFS below which the gate starts closing. At the bottom (OFF, default) the gate does nothing.

SettingBehaviour
Fader positionThreshold from 0 down to −60 dBFS; bottom = OFF
Ratio1 : 4 below the threshold — every dB under it is turned down 3 dB more
Rangeup to 70 dB of attenuation
Timingopens in about 0.5 ms, holds 30 ms, then closes over about 90 ms

The gate works before the compressor, so the compressor's makeup gain never lifts the noise the gate has removed.

Set it with the vocal soloed: raise the fader until the gaps go quiet, then back off 3–5 dB so soft word endings are not cut.

2Comp

The main control. Pulling the fader down does three things at once: it lowers the threshold, it raises the ratio, and it adds makeup gain that exactly cancels the reduction on a full-scale peak. The result: peaks stay put, everything under them comes up — the vocal gets denser and more forward without getting louder at its loudest point.

FaderThresholdRatioMakeup gain
0 (default)0 dBFS2.5 : 10 dB — no compression
−10−10 dBFS3.4 : 1+7.1 dB
−20−20 dBFS4.3 : 1+15.4 dB

−60−60 dBFS8.0 : 1+52.5 dB

The knee is soft (6 dB wide), and the release is automatic: short consonants and peaks are released quickly (about 70 ms) so the vocal keeps its life, while long sustained notes build up a slower release (up to about 0.9 s) that avoids pumping.

3Gain

Output level, from +10 dB to −∞ (fully off), default 0 dB. The scale is the same as a console fader: finer steps around 0 dB, wider ones towards the bottom.

Gain comes before the limiter. Pushing it above 0 dB makes the vocal louder and drives the limiter harder; the output can never go above −0.1 dBFS. When the limiter is working, the light under GAIN turns red.

4Meters

  • IN (next to GATE) — input peak level, −60 to 0 dBFS, ice-white segments.
  • GR (next to COMP) — gain reduction, lit from the top down in orange: 0 to 20 dB. It includes any reduction from the limiter.
  • OUT (next to GAIN) — output peak level, −60 to 0 dBFS; the top two segments are red (the last 3.5 dB below full scale).

Each segment is about 1.8 dB on the level meters and 0.6 dB on GR. Peaks are shown at once and fall back over about a second. The line at the bottom right of the panel shows the same values as numbers.

The numbers under the lights show each fader's exact setting.

6Mono / Stereo

STEREO (default) processes left and right together with linked gain, keeping the stereo image. MONO sums the input to mono first, so both outputs carry the same signal — useful for a mono vocal recorded on a stereo track, or one mic that leaked into two channels.

Technical notes

  • Formats: AU and VST3, macOS (Apple Silicon and Intel). Mono and stereo.
  • Latency: 1.5 ms (72 samples at 48 kHz) for the limiter's look-ahead, reported to the host for automatic compensation.
  • Detector: stereo-linked peak detector, 0.3 ms attack, 40 ms release.
  • Compressor: soft knee (6 dB), ratio 2.5 : 1 to 8 : 1 following the COMP fader, attack about 3 ms, two-stage automatic release (≈70 ms fast, ≈0.9 s slow).
  • Limiter: 1.5 ms look-ahead, 60 ms release, ceiling −0.1 dBFS. Clean below the ceiling — no saturation is added anywhere in VoxSqueeze.
  • CPU: very light; use one on every vocal.
